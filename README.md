# Town & Country Kitchen

Mobile-first React and Tailwind CSS one-page site for Town & Country Kitchen in
Norton, Kansas.

## Run locally

```sh
npm install
npm run dev
```

Create a production build with `npm run build`; preview it with `npm run preview`.
The generated static site is in `dist/` and can be deployed to any static host.

## Public listing details

- Hours shown: Monday–Saturday, 6:00 AM–8:30 PM; Sunday, 7:00 AM–2:00 PM.
- The restaurant’s public Facebook page shares photos and dated weekly menus:
  [T&C | Norton KS](https://www.facebook.com/t.and.c22).
- Food photos and the dated September 21–27, 2026 weekly-menu flyer in

Menu specials and individual prices can change. Dated specials are identified
as such on the page; guests are prompted to call for current availability and
pricing.
